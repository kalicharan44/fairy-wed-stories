# Fairy Wed Stories — Creative Research

## Scope and method

The supplied repositories were shallow-cloned and their source files, manifests, scripts, dependencies, licenses, responsive branches and linked demos were inspected. Live demos were opened where available; the Reveal Slideshow host returned HTTP 403 to the read-only viewer, so its repository source and published license were used for that entry. This is a technique study; no third-party component was copied into the application. Repository code is older in several Codrops examples, so the implementation uses the already installed GSAP, ScrollTrigger, Framer Motion and Embla APIs instead of importing demonstration bundles.

The live references below were inspected for composition and interaction patterns, not as branding templates. Claims about quality or awards are only repeated where linked to the publisher or award listing. Live sites change over time; the notes describe the observed pattern and the project-specific takeaway.

### Source-level implementation notes

- ScrollBasedLayoutAnimations uses GSAP Flip to animate between captured DOM states and ScrollTrigger to map the transition to a bounded scroll interval. Its touch branch changes resize/refresh handling; it does not make every pinned composition automatically appropriate on mobile.
- ImageExpansionTypography has multiple effect entry points rather than one general-purpose image component. Its demos use GSAP timelines and Flip; the correct takeaway is controlled image/text staging, not importing five effects.
- ScrollAnimationsGrid and ElasticGridScroll show why transforms are preferable for gallery movement, and why a handful of composited row or column transforms is cheaper than layout changes on every tile.
- The supplied examples vary in licensing. Concepts are used as references only. No demo image, icon, font, source file or vendor bundle was copied into Fairy Wed Stories.
- The application adds no library. Its existing dependencies remain GSAP/ScrollTrigger, Framer Motion and Embla. The image mask and brand typography are implemented in project-owned CSS.

## Implementation decisions and quality checks

- Adopted: warm ivory/espresso palette, bundled Cormorant Garamond under its OFL, asymmetrical photo proportions, a masked hero reveal, scroll-driven image drift, native touch galleries, variable-width Embla rails, understated progress, and differentiated desktop/mobile motion.
- Adapted: row-level social-wall parallax and image scaling. GSAP animates only image transforms while the row itself remains natively scrollable; the effect is removed for reduced motion.
- Rejected: Lenis, WebGL, new carousel packages, copied GPL/Flickity implementation, demo image/font assets, long mobile pinning, and hover-only interactions.
- Tested on the running local preview across six widths/routes. See AESTHETIC_IMPLEMENTATION_REPORT.md and SCREENSHOT_INDEX.md for capture list and measured outcomes.
- No Git checkpoint could be created because the Fairy checkout is not a Git repository. A dated, hashed ZIP backup was made before edits.
